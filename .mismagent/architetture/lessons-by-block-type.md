# Lessons by block type

Review history `mismagent.py pack` carries forward to the next workers/reviewers of each type.
Not regenerated by a full harvest of dev-architecture — this file is the exception, a review
history the code cannot re-derive. Strike (`~~…~~`) a lesson to drop it from the pack.

## port

- The Ambiente/Finta (D1) must enforce the supplier's own state-transition rules, never looser
  ones: a contract test seeded `fallisciElaborazione` straight from `in_attesa`, and the D1
  `AmbienteFinto` accepted it (APERTI → FALLITA), hiding that the real supplier allows
  `completa`/`fallisci` only from IN_CORSO (`Elaborazione.kt:59-66`, `nonAmmessa(IN_ATTESA,
  FALLITA)`) — the contract case was unrealizable in D2. See
  `sintesi/applicazione/src/testFixtures/kotlin/.../LettoreTrascrittoContratto.kt` AC-S4 and
  `LettoreTrascrittoFintaTest.AmbienteFinto` (rework/lettore-trascritto-sintesi-1.md).
- Sibling ports built in parallel commonly both edit the same module's `build.gradle.kts` (e.g.
  adding `api(:kernel)` / `testFixturesApi(testFixtures(:kernel))`) — expect a merge conflict
  against `integration/<feature>` when composing; resolve to the union of both additions, never
  drop one sibling's dependency line (rework/modello-linguistico-1.md).
- Finta fields written from more than one thread need `@Volatile` even in a test double —
  `ModelloLinguisticoFinto.kt:16` `esito`/`ultimaRichiesta` were set/read cross-thread without it
  (recurring LOW, pre-release.md).
- A contract test case must actually reach its own assertion on the fake (D1), not only be
  meaningful on the real adapter (D2) — `ModelloLinguisticoContratto.kt:90` AC-S13's mid-call flip
  never reaches its assertion on the fake; design each case to discriminate on every dimension it
  claims to cover, not just the one (e.g. D2) it was written for (pre-release.md).

## aggregate

- Before pinning a Value Object's shape, check whether its owning block would create a manifest
  wave cycle with the aggregate that needs it; if a later-wave block would own it, move the VO
  (and its invariant test) into the consuming aggregate instead of leaving a forward pin (D-0001,
  decisions.md — `LunghezzaMassimaParole` moved into `riassunto`).
- Don't add a new mandatory `Esito`/`ErroreSintesi` variant for a failure nobody outside the
  aggregate reads (e.g. a malformed decode token never surfaced to a user) — return nullable
  instead and reserve pinned error variants for user-trippable violations per ADR 0003 (D-0002,
  decisions.md — `TestoConVoci.decodifica`).
- `ricostituisci` and accessors must defensively copy collections, not keep or return the
  caller's own list by reference — otherwise the caller can mutate the aggregate's state from
  outside, breaking "state captive of the root" (pre-release.md — `Riassunto.kt:156`, `:55-58`).
