# Manifest delta — native Mutex wait during an Elaborazione (ADR 0017, closes spike attesa-mutex-estrazione)

Source: ADR 0017 (decisions/0017-attesa-mutex-estrazione.md). Decision: (b) + (c). One shared, fair
native Mutex, held for one native call at a time, with a wait that can be interrupted. The only long
wait is diarization. On the S3 card it becomes a visible, cancellable wait. (a) is rejected.
Constant: `SOGLIA_ATTESA_VISIBILE_MS = 2000`, defined once, in the S3 presenter.

## Boundary `tec-ml-sherpa` (owner ml-sherpa-motore): re-pin the signature text
- `snastro.ml.MotoreSherpa`: `fun <T> conSessione(config, uso): T`. It holds ONE process-wide **fair** Mutex for one native session. The wait is **interruptible**: an interrupt while waiting → `InterruptedException`, and no session, natives or `uso` run. The call is not reentrant. The Mutex is released on return or exception. Every adapter holds it for **one port call** only (ADR 0017 §1).
