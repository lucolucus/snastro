Il set di 29 icone a tratto di Snastro, che sostituisce emoji e glifi ▶ ⏸.

- Classe `sn-icon i-<nome>` (più `s` per `icon-s`). Prende il colore del testo.
- In Compose ogni file di `assets/Icons` diventa un `ImageVector`, colorato con `tint`.
- Un bottone con sola icona ha sempre un tooltip che dice l'azione.
