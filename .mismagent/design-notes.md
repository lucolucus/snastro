# Design notes

- ui (`parlanti/SchermataParlanti.kt` `MenuAltreAzioniParlante`, `registrazione/SchermataPannelloVoci.kt` `MenuAltreAzioniCarta`): the "⋯" button + `DropdownMenu` is still written by hand there; the shared `stile/MenuAltreAzioni.kt` (slice 01) could replace both. `MessaggioInlineErrore` is written four times (`progetti/PannelloNuovoProgetto.kt`, `registrazioni/SchermataRegistrazioni.kt`, `parlanti/SchermataParlanti.kt`, `registrazione/SchermataRegistrazione.kt` — `grep -rn 'fun MessaggioInlineErrore' ui/src/main`); one shared component in `snastro.ui.stile` would remove the copies — beyond slice 01.
- mm (tool): a refactor that moves a file cited by a conventions topic cannot pass `mm check --base`: either the skill cites a missing path, or the human's file changed since Base (seen in slice 06, acceptance-tests.md "Shown by"). A conventions-flow step before/inside such slices, or an exemption for path-only updates logged in conventions-proposals.md, would remove the conflict.
- tests/acceptance (`EliminaProgettoDallaListaTest.kt:53`): the real session's scope runs on an implicit `Dispatchers.Default`, against the acceptance-tests topic (use `conScopeDiProva`/`backgroundScope`); `SessioneProgettoImpl.chiudi` cancels and waits (`SessioneProgettoImpl.kt:233`) — check whether a test-scheduled session closes cleanly before moving it.
- ui (`progetti/ProgettiPresenter.kt`): the constructor's `cartellaUtente` defaults to `""` only because EX-1..3's acceptance test (`tests/acceptance/.../EliminaProgettoDallaListaTest.kt:122`, outside slice 02) builds the presenter with four arguments; making it required (and passing it there) would leave one way to build it. The presenter is also at detekt's `TooManyFunctions` limit (10 functions, threshold 11): `chiudiAvvisoEliminazione` is a lambda in `azioni` for that reason — the next S1 action needs a split (e.g. the delete confirmation flow in its own holder).
- ui (`testi/TestiProgetti.kt` `MESSAGGIO_CONFERMA_ELIMINA_PROGETTO`): "La cartella del progetto viene cancellata per sempre" is no longer exact since slice 02 (the user's own files stay, EX-9); the wording is the human's call (no example covers it).
- tests/acceptance (`EliminaConLockECodaTest.kt:158`): the EX-6 "nothing deleted" check lists only top-level names and excludes every `progetto.db-*`; the acceptance-tests topic asks for recursive relative paths excluding only `-wal`/`-shm`.
