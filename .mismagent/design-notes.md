# Design notes

- ui (`registrazione/SchermataPannelloVoci.kt` `MenuAltreAzioniCarta`): the voice card's "⋯" differs from the shared `stile/MenuAltreAzioni.kt` — small button, `MenuSn` container (raised, `radiusDialog`, `line` border), no focus return (L742b). AC-586 (`features/trascrizione-con-parlanti/building-blocks.yaml:3176`) lists the "Altri" menu among those with the raised container, while `MenuAltreAzioni` (S1, S2 rows, and S4 after slice 11) uses a plain `DropdownMenu`: which container every "More" menu uses is a visual choice for the human; once decided, `MenuSn` moves to `snastro.ui.stile` and the card can use the shared component (with a `piccolo` option).
- mm (tool, not this repo): a refactor that moves a file cited by a conventions topic cannot pass `mm check --base`: either the skill cites a missing path, or the human's file changed since Base (seen in slice 06, acceptance-tests.md "Shown by"). A conventions-flow step before/inside such slices, or an exemption for path-only updates logged in conventions-proposals.md, would remove the conflict — to report upstream to mismagent.
- avvio tests `SessioneProgettoImplTest.kt:70`, `SessioneProgettoImplChiudiTest.kt:67`, `RinominaRegistrazioneTest.kt:49` (package `snastro.avvio.progetto`): sessions still on an implicit `CoroutineScope(SupervisorJob())` (Dispatchers.Default, never cancelled by the test); `conSessioneDiProva` (SessioneDiProva.kt) now offers the cancelled one — outside slice 09's scope.
- ui `progetti/EliminaProgetto.kt` `ConfermaEliminaProgetto`: now also drawn by `SchermataShell`, with `progetti-*` test tags and `PannelloSuVelo` from `progetti/PannelloNuovoProgetto.kt`; if a third screen needs the veil panel, `PannelloSuVelo` belongs in `snastro.ui.stile`.
- avvio `progetto/SessioneProgettoImpl.kt`: the file sits at detekt's file `TooManyFunctions` limit again (10 top-level, threshold 11; `./gradlew detekt` reported "with '12' functions" before slice 05 moved `LockCartella`/`acquisisciLock`/`rilasciaLock` to `LockCartella.kt`); the next session feature will need another cohesive extraction (e.g. `creaCartellaLibera` + `validaCartellaProgetto` into a folder-layout file).
- ui (`testi/MessaggiErrore.kt:38-39`): `ErroreSessione.ProgettoGiaAperto` (apri) and `ProgettoApertoAltrove` (elimina) are two members for one idea with near-identical texts; merging them changes the port contract (`SessioneProgettoContratto`) and two texts — worth it only with the next session-error change (release review R0-1, naming). Same review: `SessioneProgettoSeams` (`avvio/.../SessioneProgettoImpl.kt:370`) is the one English name in the glossary.
- cross-platform (`.mismagent/profile.md`, "nothing Mac-only"; release review R0-1 advice, unverified — no Windows host): `percorsoDaCasa` recognises only `/` (`ui/.../testi/TestiProgetti.kt:81`); S1's empty subtitle says "sul tuo Mac" (`TestiProgetti.kt:30`); `cancellaContenutiSnastro` deletes `.lock` while its `FileChannel` holds the lock (`SessioneProgettoImpl.kt:197`, `CancellazioneCartella.kt:20`) — on Windows the file may stay delete-pending, so every delete could end `RestanoFileUtente`/`InParte` (assumption: check with a probe on a Windows runner before a Windows release).
- ui S1/shell (ADR 0041, Consequences): `CorsaSingola`/`ShellPresenter.corri` run committing operations (`crea`, `elimina`) through `nonFataleRegistrato`, so an `Error` after their commit is caught and logged, not propagated as D-0065 says for S2/S4; whether S1 and the shell move to `eccezioneRegistrata` changes their contract (presenter-split) — the human's call.
- CLAUDE.md `## mismagent` has no `smoke:` line (release review R0-2 advice); a candidate is `./gradlew :avvio:test --tests 'snastro.avvio.smoke.SmokeTest'` (drives `eseguiSmoke`, the path of `main --smoke`) — CLAUDE.md is the human's to edit.
- ui S2 row commands (slice 18): each of the 7 callers of `StatoS2.comandoDiRiga` writes `withContext(io) { comandoConfermato("<op>") { … } }` and its operation name twice (runner log + `comandoConfermato`), because the slice keeps `comandoConfermato` inside the command (`RegistrazioniPresenter.kt` `modificaData`..`annullaElaborazione`, `FlussoEliminaRiga.kt` `conferma`); a runner that also knew `io` and wrapped `comandoConfermato` under the same name would take the plain call — an architect's call on ADR 0041 §4. Design pass R1: take it together with moving the row commands out of `RegistrazioniPresenter` (release review R0-3, simple design worst place 3), now that presenter-split (2026-10-09) lets the row commands' collaborators move into a public bundle per holder; the runner would take `io` and wrap `comandoConfermato(operazione)` itself.
- ui `registrazioni/RigaRegistrazioneItem.kt`: the one S2 view file left with a file-level `TooManyFunctions` (13 functions; `./gradlew :ui:detekt` without it: "File '…/RigaRegistrazioneItem.kt' with '13' functions detected. Defined threshold inside files is set to '11'"); the generic inline editor (`CampoInline`, `CampoDataInModifica`, `ConSuggerimento`, `Interpretato`, `aOra`/`aData`/`formattaOra`) is a unit of its own and would fit a file of 6, dropping the suppression — slice 21 kept the slice's "row and its inline fields" grouping.
- sintesi R1 (slices 22–23, for whoever picks the approach after spike H1): `:llama-jni` offers no repetition penalty and no token stream — `Sampling` has only `temperature`/`topK`/`topP`/`seed` (`llama-jni/src/main/kotlin/io/github/lucolucus/llamajni/Sampling.kt:11-16`), `GenerateOptions` only `maxTokens`/`grammar`/`grammarRoot`/`lazyGrammar`/`sampling` (`GenerateOptions.kt:12-18`), and `generate` sees the text only at the end (`LlamaModel.kt:24`, a `cancel: () -> Boolean` polled by the library). So "stop at the first repeated item" or a penalty is a change to the separate library (ADR 0027); the cancel lambda alone can enforce a time budget (EX-18's 600 s) but cannot tell a loop from a slow run. Each answer is one `riassumi` = load, open, generate once, close (`sintesi/adattatori/.../ml/ModelloLinguisticoLlama.kt:22-27`): a two-pass approach pays the open twice unless the adapter keeps the model open across both passes.
- ui `RegistrazioniPresenter` (21 parameters under `LongParameterList`, `RegistrazioniPresenter.kt:97-121`) still follows the old frozen-constructor rule: its extracted flows (`FlussoImporta`, `FlussoEliminaRiga`, `FlussoIncontro`) receive their collaborators one by one; presenter-split (2026-10-09) now asks for one public bundle per holder built in `avvio/Presenter.kt`.
- ui `RiassuntoPresenter.kt` `scaricaModello` and `apriFonte` (slice 26): a handled fault is logged but shows no generic message; non-fatal-faults (2026-10-09) asks for M1(b)'s generic message at non-committing edges too.
- ui test fixture `AmbienteVoci.kt:156-157`: two stacked KDoc blocks — the `ADR 0036 ... [chiamateTraParti]` one is orphaned above `vociIncontro` and should move to `traParti` (line 161).
- ui `StatoVoci.kt` (slice 27): handled faults in `ricaricaParlanti`, `calcola` and `avviaTraParti` are logged but show no generic message; show it while keeping the card/proposal outcomes and follow-up (non-fatal-faults, 2026-10-09).
- ui `registrazione/RegistrazionePresenter.kt` (slice 28): `sbobinaturaOSicuro` and `intestazioneParte` log handled faults without a generic message; `carica` and `statoSenzaTrascritto` show only the transcript-load error. Show M1(b)'s generic message keeping the fallbacks (non-fatal-faults, 2026-10-09); no test pins `SomiglianzaVoci.suIo`'s committing-fault behaviour.
- ui `parlanti/ParlantiPresenter.kt` (slice 29): `carica` initial/retry failures show only the load-specific error; show M1(b)'s generic message keeping the error/retry state (non-fatal-faults, 2026-10-09). Refresh failures and `riproduci` already show it.
