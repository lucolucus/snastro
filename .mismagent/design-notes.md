- mm (tool): a refactor that moves a file cited by a conventions topic cannot pass `mm check --base`: either the skill cites a missing path, or the human's file changed since Base (seen in slice 06, acceptance-tests.md "Shown by"). A conventions-flow step before/inside such slices, or an exemption for path-only updates logged in conventions-proposals.md, would remove the conflict.
