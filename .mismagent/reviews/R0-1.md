## Dimensions below 4 and the three worst places

1. **Simple design — `ui/src/main/kotlin/snastro/ui/registrazioni/RegistrazioniPresenter.kt:103`**: 21 constructor parameters, 56 functions, `LargeClass` suppressed. Its view `SchermataRegistrazioni.kt` (1503 lines, file-level `TooManyFunctions`) is the companion hotspot. Fix: split by user flow per presenter-split (`internal` holders over the existing `_stato`, the way `FlussoEliminazione`/`CorsaSingola` split `ProgettiPresenter`), removing the suppressions.
2. **Error handling — the cause of a non-fatal fault is dropped in R0's delete paths.** `ui/src/main/kotlin/snastro/ui/progetti/CorsaSingola.kt:51` and `ui/src/main/kotlin/snastro/ui/EliminazioneProgettoAperto.kt:53` do `catturaNonFatale { … }.getOrNull()` with no `onFailure`. This is CR-7 ("no `runCatching` whose failure is ignored"). Real causes that would leave no trace: an `IOException` from `FileChannel.open(".lock")` on a read-only folder (`LockCartella.kt:14`), or the `ExecutionException` that `togliDallaLista` deliberately throws (`SessioneProgettoImpl.kt:246`). Fix: `.onFailure { log… }` before `getOrNull()`, as `CodaCondivisa.kt:256` already does with `segnalaSfuggito`. Related:
   - `ui/src/main/kotlin/snastro/ui/testi/MessaggiErrore.kt:37`: the one-argument `messaggioPer(ErroreSessione)` silently passes `cartellaUtente = ""` for `CartellaNonTrovata`. display-paths forbids exactly this ("a one-argument `messaggioPer` must not silently assume an unknown home for path-bearing errors").
   - `EliminazioneProgettoAperto.kt:59` calls that one-argument form although it holds `cartellaUtente` (`:29`). Fix: use `messaggioPer(esito.errore, cartellaUtente)` there, and make the one-argument entry point unable to reach the path-bearing branch.
   - `togliDallaLista` is the only `SessioneProgetto` operation whose failure is an exception rather than an `Esito` (`ui/.../SessioneProgetto.kt:32`).
3. **Duplication — the shell's single-flight runner, `ui/src/main/kotlin/snastro/ui/ShellPresenter.kt:76-98` and `:139-156`**: two hand-rolled copies (try / generic catch / reset in `finally`) plus the third in `EliminazioneProgettoAperto.kt:45-67`. Also the acceptance-test harness is copied six times. Fix: one private runner in the shell used by `avvia` and `chiudi` (logging the cause; see point 2). For tests, one shared S1 test harness next to `ConSessione.kt` (`dati`, `elimina`, the presenter scope, one `contenuto`).
