# 0006 — Persistence: SQLDelight + sqlite-jdbc, one DB per Progetto, forward-only verified migrations

## Context
Knob K4. Single user, local, per-project source of truth (`Registrazione`, `Elaborazione`,
`Trascritto` with `Voce`/`Segmento`, `Parlante` + `ImprontaVocale`, `Attribuzione`). The project
must be a self-contained folder (ADR 0010). The persistence schema is the **evolving contract** of a
single-side app. Alternatives: SQLDelight · Exposed + Flyway · plain JDBC. **SQLDelight chosen
[user]** (explicit SQL incl. partial unique indexes, generated type-safe queries, build-time
migration verification).

## Decision
- **SQLDelight** (JVM, `JdbcSqliteDriver`) over **xerial sqlite-jdbc**. `:persistenza` owns the
  schema (`.sq`), the migrations (`.sqm`), the driver factory and the generated database; the
  repositories implementing each context's repository ports live in that context's `adattatori`
  module (`:progetto|:trascrizione|:parlanti:adattatori`) on top of the generated queries. JDBC /
  SQLDelight / sqlite types appear **only** in `:persistenza` and `*:adattatori` of the three
  contexts — never in `:ui`, `:audio`, `:ml-sherpa`, `:modelli`, `:avvio`, `:documento:*`
  (enforced_by) nor in the inner modules (ADR 0002). `:avvio` opens a project only through
  `:persistenza`'s factory. One database file per Progetto: `<progetto>/progetto.db`.
- Connection: WAL journal, `foreign_keys=ON`, `secure_delete=ON` (ADR 0009); one writer (the app).
- **Migrations are forward-only**: numbered `.sqm` files in `persistenza/src/main/sqldelight/
  migrations/`; a committed migration is **never edited** (a fix is a new migration); no down
  migrations. `verifySqlDelightMigration` runs in `./gradlew check`. Schema version is applied at
  open; a DB newer than the app refuses to open with a clear message.
- **Scoped exception to the profile rule "never commit DB files"**: `verifySqlDelightMigration`
  needs the committed **schema snapshots** `persistenza/src/main/sqldelight/databases/<n>.db`
  (generated by `generateSqlDelightSchema`, **schema only, never user data**). `.gitignore`
  un-ignores exactly that path; the profile rule carries the exception.
- Transactions: one SQLDelight `transaction {}` per command = the unit of work (ADR 0012).
- Set invariants INV-4 / INV-16 are backed by partial unique indexes → ADR 0007.

## Consequences
- Adding a table/column = a new `.sqm` + regenerated snapshot in the same block.
- Moving to another store later means a superseding ADR; the repository ports isolate the domain.
