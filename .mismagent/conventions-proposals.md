# Conventions proposals

- create acceptance-tests: an example's acceptance test lives in `avvio/src/test/kotlin/snastro/avvio/accettazione/`, named with its `EX-<n>`, and drives the screen's presenter over the REAL `:avvio` adapters (session, temp folders, `RegistroProgettiFinta` only for the per-user registry) with `Dispatchers.Unconfined`; the screen gets a thin Compose smoke test in `:ui` that its controls reach the presenter's actions — `avvio/src/test/kotlin/snastro/avvio/accettazione/EliminaProgettoDallaListaTest.kt`, `ui/src/test/kotlin/snastro/ui/progetti/SchermataProgettiEliminaTest.kt` (`tests/acceptance/` does not fit a Gradle multi-module build; `:avvio` is the only module that sees both the presenters and the real adapters).
- create confirm-by-typing: a destructive confirmation that asks to type a name keeps the typed text as local UI state (like the new-project panel's fields) and the rule in ONE pure function on the state (`ConfermaEliminazione.confermataDa`); the view's enabled button and the presenter's own guard (`confermaElimina(nomeDigitato)`) both call it; a failure stays inside the confirmation (`ConfermaEliminazione.errore`, like `erroreCrea` in the panel) — `ui/src/main/kotlin/snastro/ui/progetti/{ProgettiUiStato,ProgettiPresenter,EliminaProgetto}.kt` (one rule, two guards: EX-2).
