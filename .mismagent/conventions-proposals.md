# Conventions proposals

- create screen-split: a screen file that outgrows detekt's `TooManyFunctions` (11 per file) splits by flow into files of the same package, each named after its main composable; the shell (public entry, loading/error, content, list) keeps `Schermata<X>.kt`; composables called across files become `internal`, never `public`, the rest stay `private`; a shared measure lives with its owner (`internal`); a file still over the threshold keeps a file-level suppression stating its reason — `ui/src/main/kotlin/snastro/ui/registrazioni/SchermataRegistrazioni.kt`, `IncontroItem.kt`, `RigaRegistrazioneItem.kt`, `ColonnaElaborazione.kt`, `MenuAzioniRegistrazione.kt`, `BarraImportazione.kt` (slice 21: the view half of presenter-split; `SchermataShell.kt` and `parlanti/SchermataParlanti.kt` still carry the file-level suppression and would follow it)
